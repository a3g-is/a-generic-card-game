A simple card game made for my university, as a final project in my C class.

The code is somewhat messy because I had to implement everything in a single file, which was a constraint for the project. This approach may be optimized across multiple file handlers in the future.
I am proud of this project, and I can consider it my very first game, but it has many bad practices, as well as it is currently mixed with ENG/ITA languages.


To run using GCC compiler:
gcc -o output-file main.o gamelib.o -std=c11 -Wall
